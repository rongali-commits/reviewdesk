# ReviewDesk buyer delivery guide

## Daily workflow

1. Add a completed customer in **Customers**, import an approved CSV, or send the completed-customer webhook.
2. ReviewDesk schedules the active request sequence.
3. The customer opens a private link and shares feedback.
4. Remaining reminders stop automatically.
5. Review private feedback in **Feedback** and follow up when service recovery is needed.
6. Feature only stories where the customer granted permission.

## Important controls

- Keep the dashboard and webhook tokens private.
- Never upload prospects or people who were not genuine customers.
- Do not offer rewards for reviews or request a particular rating.
- Do not hide the public review option based on a customer's score.
- Monitor the sender inbox and honor opt-outs or deletion requests.

## Test before a campaign

Create one request using an email address controlled by the business. Confirm message delivery, the feedback form, the public review destination, automatic suppression, dashboard metrics, and testimonial consent before importing customer records.

## Support handoff

The delivery package should include the live URL, admin token through a secure channel, hosting ownership, sender configuration, backup notes, final scope, and the support period included with the order.
